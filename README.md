## 📌 Proyectos destacados

### [Empresa Aliada — Pronóstico ARIMA de VANISH y LYSOL](https://github.com/LuisGGarcia2/empresa-aliada-arima-vanish-lysol)

Modelado predictivo de ventas semanales mediante ARIMA, validación temporal y generación de pronósticos para apoyar decisiones comerciales.

### [Base relacional de almacén e-commerce](https://github.com/LuisGGarcia2/sqlite-almacen-ecommerce)

Diseño y análisis de una base SQLite de clientes, productos y pedidos mediante Python, INNER JOIN y LEFT JOIN.

### [Segmentación RFM de clientes](https://github.com/LuisGGarcia2/segmentacion-clientes-rfm)

Segmentación de clientes mediante Recency, Frequency y Monetary, complementada con clustering K-Means.

Análisis exploratorio de 122,002 registros para identificar tendencias, productos destacados, comportamiento geográfico y anomalías.

### [Predicción de precios de vivienda](https://github.com/LuisGGarcia2/prediccion-precios-kc-house)

Regresión lineal múltiple y álgebra matricial para predecir precios de viviendas con el dataset KC House.

### [Series de tiempo — IBM y Walmart](https://github.com/LuisGGarcia2/series-tiempo-ibm-walmart)

Análisis de estacionariedad, autocorrelación, promedios móviles y pronóstico de precios bursátiles.
